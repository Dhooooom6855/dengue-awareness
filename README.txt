ডেঙ্গু প্রতিরোধ — বাংলা সচেতনতামূলক ওয়েবসাইট

ফাইল:
- index.html: সম্পূর্ণ ওয়েবসাইট (CSS ও JavaScript একই ফাইলে আছে)

কম্পিউটারে চালানো:
1. ZIP ফাইলটি Extract করুন।
2. index.html ফাইলটি Chrome/Edge/Firefox-এ খুলুন।
3. ইন্টারনেট থাকলে বাংলা ফন্ট লোড হবে; ফন্ট না এলে ডিভাইসের ডিফল্ট ফন্টে দেখাবে।

GitHub Pages-এ বিনামূল্যে প্রকাশ:
1. GitHub-এ লগইন করে Public repository তৈরি করুন, যেমন dengue-awareness।
2. index.html আপলোড করে Commit changes করুন।
3. Repository Settings > Pages-এ যান।
4. Build and deployment থেকে Deploy from a branch নির্বাচন করুন।
5. Branch: main এবং folder: /(root) নির্বাচন করে Save করুন।
6. প্রকাশিত URL Pages পাতায় দেখা যাবে। প্রথমবার প্রকাশ হতে কিছু সময় লাগতে পারে।

নোট:
এই সাইট শিক্ষামূলক, চিকিৎসা-পরামর্শের বিকল্প নয়। চিকিৎসা-সংক্রান্ত তথ্যের জন্য সাইটের তথ্যসূত্র অংশ দেখুন।
